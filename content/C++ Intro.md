# c++ intro

i've always thought C++ was cool.

first time i touched it properly was while trying to reverse engineer
[[Superfighters Deluxe]]. that attempt failed pretty badly and i switched to C#
later, but the short time with C++ stuck because it showed me how much control
the language gives you.

DLL injection and messing with running programs felt insane at the time. made
programming feel way less abstract and way more real.

## why i want to learn it properly

main reason is simple: i want a better understanding of what's actually
happening under the hood.

C++ forces you to care about things like:

- memory
- compilation
- references and [[Pointers|pointers]]
- [[Stack vs Heap|stack vs heap]]
- performance as an actual design constraint

that's also why this connects naturally to [[Writing a ML Library in C]]. if i'm
going to build lower-level systems, i don't want to only understand them from
the outside.
