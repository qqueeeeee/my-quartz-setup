# Microservices

a software design style where large application is built as connection of smaller and independent services. 
## Purpose

It allows each service to be completely independent, meaning if one fails the others keep running, this also allows them to be flexible, from things like letting them each have a different programming language to different architecture etc, because at the end of the day the main way of them communicating would be through things like APIs and such. So, this let's them be fully individual.
