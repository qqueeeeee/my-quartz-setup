# Fishao Server

Fishao-compatible backend by reverse engineering the original protocol and
recreating enough server behavior to make the game work again.

this is one of those projects i like because it's way more interesting than
normal CRUD stuff. it forces me to care about protocols, packet structure,
backend architecture, and how games actually talk to services.

## why it matters

- it fits the hacker / tinkerer side of my interests way more naturally
- it connects low-level curiosity with actual software engineering work
- it is the kind of thing that reminds me why I like programming in the first place
