# vault style guide

basic style i want this vault to follow.

not a strict religion or anything. just rules that make it easier to maintain
without thinking too much.

## main idea

file-first, link-heavy, low-friction.

i don't want to spend more time organizing notes than writing them.

## rules

- keep one vault
- keep folders to a minimum
- keep most notes in the root
- use internal links a lot
- use `YYYY-MM-DD` dates
- pluralize categories and tags when it makes sense
- prefer plain markdown and simple frontmatter

## folder philosophy

most notes should live in the root because they're usually:

- things I wrote
- things I am learning
- project notes
- conversations / ideas / essays that relate directly to me

folders are mostly support folders:

- `References` for things outside my world like books, people, places, games, tools, etc.
- `Clippings` for things other people wrote
- `Templates` for templates
- `Daily` for dated daily-link notes if I use them
- `Attachments` for media and files

`Categories` can stay as an overview layer, but it should not become the main
way i think about the vault.

## why this matters

i want structure to emerge from links, categories, and repeated themes. not from
me endlessly deciding where a file belongs.

that's the whole point.
