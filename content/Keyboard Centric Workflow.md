# keyboard centric workflow

almost everything on my computer is based on this idea.

i hate moving my hand back to the mouse for basic stuff. if most interactions
stay on the keyboard, the whole system feels faster and less annoying.

## what that means

it shows up through a bunch of tools and habits:

- [[Tiling Window Managers]] because I like my screen layout being something I can control instantly
- [[GlazeWM]] because I still want that kind of workflow on Windows
- [[Neovim]] because it feels way more natural to me than clicking around an IDE
- [[Quartz]] because even this site is built around shortcuts and keyboard-first navigation

i tried [Zed](https://zed.dev/) for a bit because it has a nice GUI and vim
motions. but it still felt like a tool that looked right, not one that fit me.
[[Neovim]] feels more native to how i already think.

## why i care

it's not really about saving 0.4 seconds.

it's more that keyboard-heavy workflows make the system feel direct. less
friction, less context switching, fewer tiny interruptions.

so yeah, it shows up outside my local setup too:

- in how I use [[How I use Obsidian|Obsidian]]
- in how I think about interfaces in [[Quartz]]
- in the kind of tools I want to build for myself, like [[SelfForge]]
