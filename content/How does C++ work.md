C++ has two main stages in converting a .cpp file into a .exe file, these are compiling and linking done by the [[Compiler]] and [[Linker]] respectively. 

The [[Compiler]] converts the .cpp files into .obj files which are then altogether are "linked" and converted into a .exe file.
